# 设计 Spec — 新云 AI 提案工作台

> 三个方向的共同输入。只写「要说什么」，不写「长什么样」。

## 项目

给上海新云传媒做户外媒体投放提案工作台：选行业/品牌、拖预算、勾媒体、定档期，从红豆真实库存与大数据覆盖里选线路/点位，生成可给客户讲、可核对的 HTML 提案。赛题现场评委改预算/换行业，必须当场重算。

## 受众与场景

- 第一受众：INTERCITY HACK 企业评委（新云传媒/办公赛道），4 分钟路演 + 1 分钟答辩。
- 第二受众：新云销售，日常用它 10 分钟出新客户方案、2 秒改预算。
- 第三受众：客户（私立医院/银行/快消/乐园的市场负责人），看提案做决策。
- 场景：1440×900 桌面大屏为主，现场可能投屏；手机 375px 只要求可读，不要求全功能。

## 核心信息（按优先级）

1. **真库存**：431 条公交 / 861 个地铁口，2027-04-01～05-15 快照；每条都能回到空车数、合同/预定、查询档期。
2. **算得清**：刊例 × 周数 + 制作 × 折扣；100/200/500 万都不超预算；不是把数量乘 2.5。
3. **现场可改**：拖预算 2 秒重排；换行业/换锚点/只地铁/只公交都能出结果；不靠预录。
4. **可执行**：排期含 T-14 审批、分批夜间安装、雨天缓冲；直客「损一补一」/4A「误一补二」分口径。

## 情感基调

可信、克制、城市感。像城市调度台或一份被认真批注过的作战文档，不像通用 SaaS 后台，也不像 AI 生成的营销页。允许一个方向更硬朗、一个更编辑、一个更上海；不允许三版都“暖纸 + 橙点 + 全大写小标签”。

## 输出格式

- 主交付：单页工作台，1440×900 不横向滚动；375px 可读。
- 三方向初稿：每个方向 1 个完整首屏 + 长页（方案表/报价），1440×900 截图。
- 最终：`src/index.html` + `styles.css` + `app.js` + `engine.js` + `data.js`；无 CDN/无网络。
- 导出：CSV + 单文件 HTML 提案（可打印）。

## 内容清单（三版共用）

- 输入：行业（5 选 1）、品牌、预算 100–500 万、媒体（公交/地铁）、档期（Q2 4/6 周）、半径（1/3km）。
- 主视觉：真实 OpenStreetMap（在线 Leaflet 可缩放/拖动；离线 z14 快照兜底；© OpenStreetMap contributors），标 active 锚点、覆盖圈、候选、选中；地图不是装饰，是“为什么选它”的证据。
- 摘要：预算/公交辆数/地铁口数/周期/覆盖院区/站点/预估触达/预算使用率。
- 方案表：14 行左右（美华 200 万/6 周：3 口 + 11 辆），每行有空车数、单价、周数、刊例、净价、距离、理由。
- 报价：媒体刊例 → 92 折 → 制作 → 监测 0 → 净价 195.2 万 → 余额 4.8 万。
- 证据：快照时间、查询档期、合同/预定、保养、覆盖文件、替补。
- 双视图：客户/销售。
- 数据口径：2023 人流只做相对权重；地铁无站点级人流；92 折是示例。

## 已知约束

- 只写 `src/`；不碰 `data/`、`tools/`、`docs/`、`config.local.json`。
- 无 npm/构建/CDN；系统字体；数据本地 `data.js`。
- 不用第三方 logo、假医院照片、假上海 stock 图；医院名文本呈现。
- 可读性：正文 ≥14px、标签 ≥12px、点击 ≥44px、对比度 ≥4.5:1。
- 三方向必须骨架不同；最多一个方向“用力过头”。
