# 三方向 · 六候选

> 输入：`spec.md` + `brand-spec.md` + 真实 `sample-data.js`（美华 200 万/6 周：3 口 + 11 辆，净价 195.2 万）。
> 说明：本次模型没有看图能力（`read_image` 不可用），方向卡按风格库的文字 DNA 与已核实来源写；截图只作为实现结果，不冒充“亲眼看过的参考板”。

## 候选 1 · TRANSIT CONTROL / 城市调度台（做成完整版 A）

- 逻辑与来源：现实参照——Bloomberg 终端 / 机场塔台 / 地铁调度台；实现语言参考 web 风格 16「Terminal-Core Soft-Futurism」。
- 借的是什么：深色底 + 暖白字 + 单一信号色；等宽字体承担数字与状态；1px 规则线分栏；高密度表格；状态灯与“LIVE/SNAPSHOT”标签；地图占主位，控件像操纵杆。
- 主角素材：真实经纬度投影的 SVG 地图 + 14 行真实方案数据 + 大号净价数字。
- 骨架：顶部指挥条 → 左控制轨（4 旋钮）→ 中地图 → 右报价 → 下方调度清单。
- 胆量花在哪：地图上的候选点/选中线像雷达回波一样亮起；其余克制。
- form 来自内容的哪里：这个产品就是“把一座城市排成一份提案”，调度台是它真实的工作隐喻。

## 候选 2 · FIELD DOSSIER / 作战手册（做成完整版 B）

- 逻辑与来源：现实参照——POPEYE/BRUTUS 的数据跨页（日式生活杂志密排）+ 现场作战手册；编辑语言参考 east 风格 12。
- 借的是什么：白纸黑字、12 栏报纸网格、粗黑线数据格、黄马克笔高亮、红蓝笔注解、路线图上的编号圆点；正文小、信息密、留白是构图不是空白。
- 主角素材：一张 3km 路线图 + 3×3 数据格 + 14 行清单；数字用窄体拉丁/等宽。
- 骨架：报头 → 左 7 栏大标题与数据格 → 右 5 栏路线图与报价收据 → 底部排期条。
- 胆量花在哪：首屏像一本真的作战手册，标题是“200 万，先打穿 3 个口”，不是“欢迎使用工作台”。
- form 来自内容的哪里：提案本质是一份要被销售批注、被客户签字的作战文档。

## 候选 3 · MUNICIPAL MODERN / 市政现代（做成完整版 C）

- 逻辑与来源：最佳设计师——田中一光（网格上的方/圆/四分之一圆、红黑芥黄、竖排粗宋）+ 上海 1930s 市政现代主义；east 风格 9/4。
- 借的是什么：几何母题（四分之一圆、扇形、阶梯矩形）在网格上构图；米纸底 + 朱红 + 芥黄 + 钢蓝；竖排标题与横排信息并置；细双线框；数字巨大。
- 主角素材：几何化的上海地图（覆盖圈做成扇形/同心弧）+ 真实点位 + 方案清单。
- 骨架：几何报头（竖排标题 + 大号 200 万）→ 三段式（Brief / Map / Ledger）→ 底部朱红数据带。
- 胆量花在哪：报头几乎是一张海报；地图用几何构成而不是仪表盘。
- form 来自内容的哪里：上海户外媒体提案，应该长在上海自己的视觉史里，而不是硅谷 SaaS。

## 候选 4 · VIGNELLI TRANSIT STANDARDS（备选）

- 逻辑与来源：最佳设计师——Massimo Vignelli 的纽约地铁图/标准手册。
- 借的是什么：纯白底、Helvetica/Arial、红黑两色、45°/90° 线路、严格网格、无装饰；信息图优先。
- 主角素材：把 3km 覆盖画成一张交通标准图，站点是圆点，线路是直线。
- 骨架：一张大图 + 下方标准手册式表格。
- 胆量花在哪：全页只有两种颜色；没有阴影/圆角。
- form 来自内容的哪里：户外媒体就是城市交通的一部分。
- 备注：备选；和 A 一样偏“交通”，但骨架是标准手册不是调度台。

## 候选 5 · TERMINAL-CORE STANDALONE（备选）

- 逻辑与来源：秒数轮盘 web 16「Terminal-Core Soft-Futurism」。
- 借的是什么：炭黑底、暖白字、等宽字为主角、命令行式输入、2.5D 等距方块、克制光晕。
- 主角素材：命令行里的 `PLAN 200W --anchor meihua --weeks 6` + 输出清单。
- 骨架：单列终端 + 右侧 2.5D 地图。
- 胆量花在哪：整页像一个可敲命令的终端。
- form 来自内容的哪里：确定性引擎本来就是“输入命令 → 输出方案”。
- 备注：备选；整页终端属于“用力过头”，最多一张，且去掉终端手法后信息应更清楚。

## 候选 6 · SHANGHAI MODERNE DECO（备选）

- 逻辑与来源：秒数轮盘 east 4「上海摩登装饰艺术」。
- 借的是什么：深墨绿 + 金 + 朱红 + 米黄；放射扇形/阶梯塔形；双框；粗美术字；右侧日历块；底部朱红通栏。
- 主角素材：扇形覆盖图 + 月份牌式报价日历。
- 骨架：对称海报 + 中央地图 + 日历报价。
- 胆量花在哪：把报价做成一张月份牌。
- form 来自内容的哪里：上海户外广告的黄金年代就是月份牌。
- 备注：备选；最“用力过头”，若选它只用于报头/页脚，不把全页做成老广告。

## 三张完整版的选择

- **A Transit Control**：骨架=指挥台；温度=冷；密度=高；适合演示“现场改预算”。
- **B Field Dossier**：骨架=编辑跨页；温度=中性偏暖；密度=最高；适合演示“可核对、可批注”。
- **C Municipal Modern**：骨架=几何海报；温度=暖；密度=中；适合演示“上海/品牌感”。

三张骨架不同、外观家族不同；A/B/C 都不与介绍页的“暖纸+橙点+等宽小标签”完全同族。
