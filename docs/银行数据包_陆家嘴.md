## 1. 锚点修正：陆家嘴金融城

原来的「陆家嘴」geocode 落在**乡镇级街道办**（121.5320, 31.2433，confidence 25），偏到金融城东侧，所以旧覆盖里 1km 圈没有陆家嘴地铁站。

现在改用：

| 项 | 值 |
|---|---|
| 锚点 | 陆家嘴金融城 |
| 中心 | 121.509815, 31.239674（商务大厦级，confidence 75） |
| 半径 | 1km / 3km |
| 文件 | `data/coverage/覆盖分析_陆家嘴_1000米.csv` / `_3000米.csv` |

覆盖结果：

| 半径 | 总数 | 公交 | 地铁 | 说明 |
|---|---:|---:|---:|---|
| 1km | 37 | 34 | 3 | 陆家嘴站（2/14）、浦东南路（19） |
| 3km | 87 | 76 | 11 | 加商城路、豫园、浦东大道、国际客运中心、世纪大道、大世界、人民广场 |

> 3km 会跨江到豫园/人民广场，这是半径事实；选点按距离排序，核心仍是 1km。

## 7. 已知缺口

1. 世纪大道站无平台标签，不能出人流；方案里显示「无数据」。
2. 旅游 1/2/10 线、840 路无平台标签；911 路双层等 4 条线路不在红豆库存。

## 8. 复现

```bash
python -I tools/build_geo.py             # 简化线路/站点几何 → data/geo/lujiazui_media_geo.json
python -I tools/build_manifest.py
python -I tools/build_links.py
python -I data/reports/_build_reports.py # 覆盖 join + 容量
python -I tools/qa_data.py
python -I tools/build_app_data.py        # 打包进 app_data.json
```
