# 新云 AI 提案工作台 · 一页纸（定稿）

> INTERCITY HACK 湖州场 · AI＋办公 · 上海新云传媒命题
> 一句话：把「销售翻刊例、查空位、拼线路、做 PPT」变成「一句话 brief、一张地图、90 秒、一份可下单的提案」。
> 数字口径：只用已验证数字；需要在页面上实测才能确认的，一律写【待回填：xxx】，不编。
> 演示入口：`src/index-atlas.html`（ATLAS · 预算落图）。

## 1. 问题

4A 公司发来 brief（例：“陆家嘴级客流点位、5 月、几块、给折扣”），销售要在 **2 个工作日内**回：可售点位清单 + 建议排期 + 折后报价。今天的做法：

- 红豆里查空位、刊例里翻价格、地图上凭经验圈线路，三套工具来回切；
- 客户一改预算 / 行业 / 媒体，整份提案重做；
- “覆盖”靠印象，“可售”靠人肉核对，超卖风险到最后一步才暴露。

## 2. 方案

**一句话 brief → 答案先行 → 现场可改。**

```
一句话 brief（行业 / 预算 / 档期 / 媒体 / 半径 / 折扣）
   │
   ▼
锚点圈选（如陆家嘴金融城 3km）→ 大数据平台覆盖 → 与红豆可售库存对账
   │   覆盖有、红豆没有的线路不悄悄丢掉，而是明说“不在可售库”
   ▼
规则引擎选点（打分 + 贪心 + 局部交换）→ 刊例报价 → 预算条 / 账目瀑布 / 甘特排期
   │
   ▼
客户视图 / 销售视图 → 单文件 HTML 提案 + CSV
```

**屏幕从上到下**（ATLAS）：

1. 一句话 brief；
2. 答案（几个地铁口 + 几辆公交 + 净价）；
3. 预算条：整笔预算按条目切开，**悬停任一段，地图和下方清单同步高亮**；
4. 地图 + 条目；
5. 账目瀑布图（刊例 + 制作费 − 折扣 = 净价，对照预算线）；
6. 三层筛选（覆盖 → 可售 → 选中）；
7. 明细清单（每条可展开证据）；
8. 上刊甘特图；
9. 数据来源。

**钱和库存全是规则，不交给大模型**（术语解释：“规则引擎”= 写死公式的计算程序，同样输入永远同样输出，每个数能复算、能追到来源）。AI 只做“一句话 brief → 参数”：默认离线规则解析，配置 key 后走在线模型，失败自动回退；解析结果还要过允许值校验，钱和库存仍由规则引擎算。

## 5. 三档预算示例（银行 3 支行 · 2027 开门红 · 含制作费 · 税另计）

默认按 **1.0 刊例**；**0.92 折是示例假设，待销售确认**，不是公司政策（资料包没有明确折扣率）。

| 预算 / 周期 | 1.0 刊例组合 | 1.0 净价 | 0.92（示例）组合 | 0.92 净价 |
|---|---|---:|---|---:|
| 100 万 / 6 周 | 1 个地铁口 + 8 辆公交 | **98.9 万** | 1 口 + 9 辆 | **98.8 万** |
| 200 万 / 6 周 | 2 口 + 15 辆 | **197.6 万** | 2 口 + 17 辆 | **196.2 万** |
| 500 万 / 6 周 | 6 口 + 32 辆 | **495.7 万** | 6 口 + 38 辆 | **499.3 万** |

- **铁律**：预算只增减媒体数量与级别，**不靠缩短周期压价**；每档净价都不超预算。
- 页面实际选出的组合由引擎打分决定；**对外口径以屏幕为准**，上表是 2026-11-21 晚的实测值。
- 三个网点每点 1km；100 万受 1km 可售候选限制会留 1.1 万余额，页面会明说。

实测（开门红，刊例 1.0）：100 万 1 口+8 辆 98.9 万；200 万 2 口+15 辆 197.6 万；500 万 6 口+32 辆 495.7 万。
银行 200 万方案日均触达约 156.9 万人次（平台 2023-05，三个网点各取本点覆盖；同站不相加、网点间未去重，仅作相对权重）。
Top 地铁口：浦东南路 3A 号口 26,201、3B 号口 20,647；公交按线路最近网点归位。

## 6. 现场可改（评委说什么，改什么，2 秒内重算、不刷新）

| 评委动作 | 页面行为 |

| 拖预算 100 → 500 万（步长 10） | 数量 / 组合 / 预算条 / 瀑布 / 地图一起变；周期不变 |
| 只地铁 / 只公交 | 另一类归零，报价重算；只地铁若有余额，页面说明原因 |
| 切行业（五选一） | 品牌、锚点、文案、合规提示一起换 |
| 折扣 1.0 ↔ 0.92 | 页面标注“示例假设，待销售确认” |
| 客户 ↔ 销售视图 | 客户：策略 / 组合 / 排期 / 报价；销售：空车数、合同 / 预定占用、替补池、折扣底线 |

## 7. 合规与口径（页面、导出、口播同一口径；逐条见《合规与口径检查表》）

- **银行**：客户版带“投资有风险”；不承诺收益；不写产品 / 收益率 / 费率。
- **医院**：投放前须取得《医疗广告审查证明》并按批准内容发布；不作功效 / 安全性断言；不用患者或医务人员名义作证明；标注机构名称 / 地址 / 诊疗科目 / 执业许可证号。
- **食品饮料 / 保健品 / 乐园**：食品不涉疾病治疗；保健品须标蓝帽子 + 批准文号 + “不能代替药物”；乐园标安全须知，不编票价 / 活动 / 开放时间。
- **以上是行业通用清单，非法律意见，未经法务逐条复核。**
- **数据口径**：
  - 库存是快照，非实时，签约前回红豆复核；
  - 2023 人流只作相对权重；
  - 地铁触达是**区域触达**，不是闸机客流；同站多口**不相加**，站点口径用合并去重值；
  - 税 6%（增值税专票）另计，不含在预算内；监测费默认 0（合同含监测）；
  - 3km 是直线半径，不是步行等时圈；
  - 输出是提案与订单草稿，不是合同；
  - 4A 框架合同第 9–16 页未核读，页面与导出均不引用其条款；4A 框架为 2026 年版，2027 档期需重签。

## 9. AI 能力清单（如实写，不夸大）

| 能力 | 用在哪 | 现状 |
|---|---|---|
| 行业 / 品牌叙事 | 提案“品牌理解”一节 | 行业模板 + 数据注入（如陆家嘴人群画像），不是现场调用大模型 |
| 锚点圈选与覆盖 | 品牌 → 地标 → 候选媒体 | 规则 + 大数据平台 |
| 组合优化 | 预算内选点 | 确定性打分 + 贪心 + 局部交换 |
| 报价计算 | 刊例 → 折扣 → 净价 | 规则引擎（金额为整数元） |
| 线路理由 | 每条线路的人话解释 | 模板 + 数据注入 |
| AI 解释 | 方案为什么这么选（锚点/主次/线路） | **已启用**：DeepSeek 生成 120–180 字；未配置时用模板（`src/ai-explain.js`） |
| 合规初筛 | 金融 / 医疗等文案提示 | 规则库（非法律意见） |
| brief 解析 | 把自然语言 brief 转成参数 | **已启用**：默认离线规则，配置 DeepSeek key 后走在线模型，失败自动回退（`src/brief.js`） |

> 原则：数字不交给大模型；大模型只适合“表达”和“初筛”，不适合对钱和库存负责。

## 10. 已知局限（主动承认）

1. 已导入 **4 段 2027 档期库存**（开门红 / 春季 Q2 / 暑期 / 中秋国庆），每段独立快照；切档期会换库存，不假装有。
