## 2. AI 能力清单

| 能力 | 用在哪 | 实现方式 | 输入 → 输出 |
|---|---|---|---|
| 品牌/行业洞察 | 提案第 1 节 | LLM + 行业模板 | 行业/品牌 → 人群、场景、核心信息 |
| 锚点解析 | 门店/院区圈选 | 规则 + 公开信息 | 品牌 → 门店/院区/地标列表 |
| 覆盖分析 | 锚点 → 候选媒体 | 大数据平台 | 坐标+半径 → 周边公交/地铁 |
| 组合优化 | 预算内选点 | 确定性贪心/交换 | 候选池+预算 → 方案清单 |
| 报价计算 | 刊例→折扣→净价 | 规则引擎 | 清单+合同口径 → 报价表 |
| 线路理由 | 每条线路的解释 | 模板 + 数据注入 | 方案条目 → 人话理由 |
| 合规初筛 | 金融/医疗/保健品文案 | 规则库 | 文案 → 风险词/必填项 |
| 提案叙事 | HTML 章节 | LLM/模板 | 方案 JSON → 提案文本 |
| 异议 Q&A | 答辩辅助 | 检索方案 JSON | 问题 → 基于方案的回答 |

> 数字不交给 LLM：选点、算价、库存判断全部确定性；LLM 只做表达与初筛。

## 3. 数据使用说明

- **红豆广告媒体管理系统**：公交 431 条 / 地铁 861 个口的库存、合同、预定、空车数；查询档期 2027-04-01～05-15；导出快照。
- **新云大数据可视化平台**：2023 年区域人流、媒体覆盖分析、AI 线路；覆盖结果含经纬度。
- **赛题资料包 00–08**：企业介绍、台账、流程、合同、结案样本、历史提案、刊例、系统说明。
- **公开信息**：品牌门店/院区/园区位置与 campaign 信息；仅用于锚点，标注来源。
- **不使用**任何其他真实企业系统；客户与业务数据已脱敏。

## 4. 已知局限

- 库存是**快照**，签约前需重新查询；页面显示快照时间。
- 人流为 **2023 年**数据，只做相对权重，不代表 2027 绝对值。
- 品牌门店/院区位置来自公开信息，需销售复核。
- 折扣/代理费/返点按合同与培训口径参数化，页面不写死。
- 覆盖模型为启发式，不是 agent-based 仿真；曝光为预估。
- 未接入真实签约/财务系统；输出为提案与订单草稿，不是合同。
- AI 文案需人工复核；合规规则不是法律意见。

## 5. 一句话

把“销售翻刊例、查空位、拼线路、做 PPT”变成“四个旋钮、一张地图、90 秒、一份可下单的提案”。
