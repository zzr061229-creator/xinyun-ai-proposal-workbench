# 合规与口径检查表

> 用途：路演前逐条打钩，确认「页面 / 导出 / 口播」三处该出现的提示都出现了、不该出现的都没出现。
> 符号：✅ = 必须出现；○ = 建议出现（时间够 / 被问到时）；— = 不需要；✗ = **不得出现**。
> 声明：行业合规条目是**通用清单**（来源：《广告法》及行业通用规定，见 `data/config/industries.json`），**未经法务逐条复核，不是法律意见**。页面和导出里必须保留这句话。
> 术语：“页面”= 工作台屏幕；“导出”= 导出的 HTML 提案 / CSV；“口播”= 路演现场说的话。

## 四、路演前自检（5 分钟）

1. **导出的 HTML / CSV 搜禁词**（应全部 0 命中）。在项目根目录运行：

   ```powershell
   Select-String -Path "导出的文件路径.html" -Pattern "保本|稳赚|无风险|保证收益|治愈|根治|疗效|最好|第一|88 ?折|底线|总部"
   ```

   其中“88 折 / 底线”只允许出现在**销售视图**，不允许出现在客户版导出；“总部”不得出现在浦发相关文案里。

2. **客户视图 + 导出各检一遍必带提示**：
   - 银行：“投资有风险”；
   - 医院：“医疗广告审查证明”；
   - 保健品：“不能代替药物”；
   - 乐园：“不在可售库 / 全公交”；
   - 全部行业：快照时间、2023 人流相对权重、税 6% 另计、“行业通用清单，非法律意见”、OSM 归属。

3. **看一眼页面是否含 logo / 外链图片**：应为 0。

4. **口播稿过一遍“禁说清单”**（见《路演脚本_4分钟.md》第五节）。

5. **五行业配置已对齐**：页面显示浦发/陆家嘴金融城、美华、农夫山泉/人民广场、汤臣倍健/徐家汇、上海迪士尼/迪士尼 3/5km，与拍板一致；和睦家/嘉会不在界面。
