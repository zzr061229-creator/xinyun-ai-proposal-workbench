# 数据接入实测

> 2026-11-21 · 实测环境：本机 Windows + 系统代理 `127.0.0.1:7897` + ZCode 内置浏览器（IAB）

## 结论

| 平台 | 能否命令行/API | 实测结果 |
|---|---|---|
| 红豆 | ✅ 可以 | Python + 代理直接调 `admin-api`；公交 431 条 / 地铁 861 条，与界面导出一致 |
| 大数据 | ⚠️ 接口存在，但本机 CLI 不通 | `POST /nearby/geocode`、`POST /baseInfoLine/matchCoverLines` 在 IAB 内正常；Python/curl/Playwright 直连 38880 被代理/TLS 阻断 |

## 一、红豆：已验证可用

### 接口

```text
GET /admin-api/orders/media-inventory/bus/page?pageNo=1&pageSize=100&startDate=2027-04-01&endDate=2027-05-15
GET /admin-api/orders/media-inventory/metro/page?pageNo=1&pageSize=100&startDate=2027-04-01&endDate=2027-05-15
GET /admin-api/orders/media-inventory/bus/export-excel?...
GET /admin-api/orders/media-inventory/metro/export-excel?...
```

### 鉴权

```http
Authorization: Bearer <ACCESS_TOKEN>
tenant-id: <tenantId>
```

Token 在红豆页面的 `localStorage.ACCESS_TOKEN` 里；`config.local.json` 保存（已 gitignore）。

### 命令

```bash
python -I tools/fetch_hongdou.py --start 2027-04-01 --end 2027-05-15
```

输出：`data/inventory_live.json`。

实测结果：

```json
{
  "bus":   { "total": 552, "rows": 431, "free": 1376 },
  "metro": { "total": 861, "rows": 861, "free": 824 }
}
```

与页面导出的 431/861 完全一致。

### 两个坑

1. **接口 `total` 是原始条数（552），不是可售条数（431）**；页面会过滤不可售资源，所以分页返回长度不均匀。
2. **同一 `resourceId` 可能对应多种媒体形式**（如 955 路的“大三侧/车身三侧”），去重必须用 `(resourceId, mediaName)`，否则会漏 11 辆可售车。

### 导出接口

浏览器里可用；Python 走代理调 `export-excel` 会偶发 `SSLError/ProxyError`，但分页 JSON 足够重建数据，**不依赖 Excel 导出**。

## 二、大数据平台：接口存在，CLI 受网络限制

### 接口

```http
POST /nearby/geocode
{"address":"静安寺","city":"上海市"}
```

返回：`name/address/lng/lat/level/confidence`。

```http
POST /baseInfoLine/matchCoverLines
{
  "radius": 1000,
  "mediaTypes": ["bus", "metro"],
  "lineScope": "self",
  "centers": [{"name":"静安寺","address":"上海市静安区南京西路1686号","lng":121.45175364824533,"lat":31.229850413739243}]
}
```

返回数组，字段包括：

- `lineName` / `mediaType`（bus/metro）
- `minDistance`（最近距离）
- `nearestStaName` / `nearestStaLng` / `nearestStaLat`
- `centerName` / `centerLng` / `centerLat` / `radius`
- `linePath`（服务端线路文件路径，前端画线用）

### 人流/画像指标接口（2026-11-21 实测）

```http
POST /label/queryThirdLabel
firstLabel=公交|地铁出入口&secondLabel=
```

返回每个标签的 `id / firstLabel / secondLabel(级别) / thirdLabel / ext1`；`id` 即指标接口的 `labelIds`。

```http
POST /bbf8e41e454b47126290905525c69f7
queryType=1&indicatorType=visitorsFlowrateAndcrowdSpeed&dataMonth=202305
labelIds=474&gridIds=&extOptions={"gridType":"500","underground":"0"}
```

`indicatorType` 可用：`visitorsFlowrateAndcrowdSpeed`（人流）、`crowdAge`、`crowdGender`、`crowdConsumption`、`crowdHouse`、`crowdPhoneNew`、`regionAttribute`（POI）、`circleCross`（商圈边界）。

人流返回字段：

| 字段 | 含义 |
|---|---|
| `coverPeoplesPV` | 区域覆盖人群-日均人次 |
| `coverPeoplesUV` | 区域覆盖人群-日均人数 |
| `coverPeoplesPVAccurate` | 触达人群-日均人次（方案优先） |
| `visitorsFlowrate` | 四段分时原值（平台未标单位，只作相对比较） |

注意：

- 数据月份由 `dataMonth` 控制（当前页面默认 2023-05，`202305`）。
- 同一地铁站各口的 PV/UV 相同，触达按口不同；多口合并查询会去重，**不能把各口相加**。
- 世纪大道站无平台标签；旅游 1/2/10 线、840 路无标签。
- 已落盘：`data/footfall/lujiazui_202305.json`（`python -I tools/build_footfall.py` 合并原始 JSON）。

### 鉴权与网络

- 平台是 `jsessionid`（HttpOnly）+ 图形验证码；`document.cookie` 读不到。
- 本机 Python/curl/Playwright 直连 `https://flairmedia.com.cn:38880` 均失败（`400 plain HTTP` / `ERR_CONNECTION_CLOSED/TIMED_OUT`）；IAB 内正常。
- 说明 38880 的访问依赖 ZCode 内置浏览器的网络路径/代理，不是普通命令行能直接复刻的。

### 可行做法

1. **预计算**：在 IAB 里对 10 个锚点跑覆盖分析（人民广场/美华/嘉会/和睦家/迪士尼/陆家嘴/徐家汇，1/3km，迪士尼 5km；另加浦发上海分行/九江路支行/徐家汇支行各 1km），导出 CSV（已验证，18 个文件）；
2. **现场换锚点**：用 IAB 现场跑，或把 IAB 的 fetch 结果保存成 JSON；
3. 若必须独立 CLI：需要在能访问 38880 的网络环境里跑 Playwright，并复用登录态（验证码不绕过）。

## 三、推荐刷新策略

```text
红豆 API（Python CLI）──> data/inventory_live.json
大数据 IAB（预计算/现场）──> data/coverage/*.csv
                                   ↓
                          工作台（静态快照 + 可选刷新）
```

- **演示前**：跑一次红豆 CLI + 10 个锚点覆盖，生成快照；`tools/build_app_data.py` 打包为 `data/app_data.json`。
- **路演现场**：用快照保证 90 秒；评委质疑时切到红豆/IAB 现场复核。
- **不要**做秒级同步：库存按天变化，签约前重查即可。

## 四、安全

- `config.local.json` 含 token，已加入 `.gitignore`，不要提交。
- 接口是比赛账号的内部接口，不是公开 API；封装成 adapter，路径变化时只改一处。
